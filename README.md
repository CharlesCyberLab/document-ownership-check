# document-ownership-check

It checks that the user requesting access owns the document.

## Risk
It could lead to data theft if the document contains sensitive information or details.

## Control
It checks if the user requestimg access is the owner of the document.

## LImitations
This is a guided learning exercise using fictional documents and simulated users. It does not verify the identity of the person typing the username, so it is not a real login system.

## Test results
All eight ownership-check tests passed. The actual result matched the expected result in each case.
